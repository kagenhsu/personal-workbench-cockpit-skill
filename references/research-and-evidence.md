# 外部案例與證據分級

需要研究控制台案例、Skill、框架、價格、服務能力或法規時才讀本文件。

## 來源順序

1. 官方文件、原始碼、標準或第一方公告。
2. 原作者完整分享、影片、文章或可追溯帳號。
3. 可靠媒體、技術文章或具方法說明的實作紀錄。
4. 社群復刻、Demo、論壇與二手整理。
5. 搜尋摘要、轉貼、無作者頁面與推測。

每筆至少記錄：名稱、來源類型、發布／更新日期、查核日期、可信度、可確認事實、不可確認項目、網址、是否允許商用或復刻。

## 判斷規則

- 同名頁面、提示詞或 HTML 不等於官方 Skill。
- 可加入主畫面不等於已符合 PWA 技術條件。
- 有 UI 不等於有資料庫、登入、同步、備份或權限。
- localStorage 是瀏覽器本機資料，不是跨裝置私人後端。
- 陌生 Skill、HTML 或專案先看來源、依賴、網路請求、秘密存取、授權和更新狀態；只記錄來源不代表允許安裝。
- 不複製他人姓名、肖像、品牌、提示詞全文或未授權視覺資產；抽象成可說明的產品方法。

## 研究輸出

把內容分成：

- 已確認事實。
- 合理推論，並標明推論依據。
- 待驗證項目。
- 可採用做法。
- 不採用做法與理由。
- 對目前專案的影響與優先級。
