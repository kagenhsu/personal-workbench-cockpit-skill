- 正式資料真相唯一且有紀錄；快取、假資料與正式資料清楚分開。
- 匯出可讀、匯入前可預覽、版本不相容會阻擋，還原需要再次確認。

## 手機與 PWA

- 390px 與 430px 不出現非預期橫向溢出。
- 主要觸控區至少約 44px，文字無需縮放即可閱讀。
- 底部導覽考慮安全區，不遮住主要操作與表單。
- 鍵盤開啟時仍可看到輸入欄與送出／取消。
- 若宣稱 PWA：有 manifest、適合圖示、HTTPS、standalone、離線／斷線狀態與可預期的快取更新策略。
- 手機與電腦要共用資料時，透過受保護後端同步，不以瀏覽器 localStorage 假裝同步。

## 安全與權限

- 未登入、錯誤角色與跨使用者存取會被拒絕。
- 若有帳號系統，登入、登出、session 到期與帳號復原行為都有明確安全結果。
- 敏感資料不出現在公開頁、前端 bundle、日誌、截圖或教學假資料。
- API 寫入有伺服器端驗證；重要變更有活動或稽核紀錄。
- AI 重要寫入先預覽，核准後才套用；刪除、公開、付款與外部訊息另行確認。
- 秘密不寫進版本庫；部署環境有成本與失敗停止條件。
