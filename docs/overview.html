01 · 先看懂這件事

先知道它能幫你做什麼

這個 Skill 是我們自己的工作規則，不是某一個 AI 軟體。你可以把它交給 Codex、Claude Code 或其他 AI 開發工具，先釐清工作需求，再協助做出可以使用、可以檢查的工作台。

適合新手適合開發者可搭配 Codex 與 Claude Code

它會怎麼幫忙

從一句話，到真的能使用的工作台

  1. 先問清楚問題

    辨識新建、改版、新增功能、資料流程或明確錯誤

  2. 一起選做法

    針對目標提出兩到三個方案，說明優點、限制與驗收方式

  3. 整理成工作步驟

    區分正式資料、草稿、待分類與待確認內容

  4. 用過再調整

    保留結果回寫、學習進度、備份與下一次調整依據

系統完成後

AI 不是只在外面聊天，而是能進入你的工作流程

你的系統負責保存資料與提供操作，AI 負責讀懂相關內容、整理重點、提出建議；你確認後，AI 才協助執行，結果再回到系統裡。

01系統存資料任務、文件、狀態
02AI 讀取只看允許的範圍
03AI 提醒與建議找重點、找異常、排下一步
04你確認後執行必要時寫回結果
用一句話理解

AI 是會協助思考與處理的夥伴；你的系統是資料與工作的場所。兩者透過受控的連接合作。

進階說法

系統要提供可被 AI 呼叫的功能，並設定資料範圍、權限與確認點。MCP 可以理解成讓 AI 連接這些功能的橋接方式；Agent 則是負責一段工作的 AI 角色。

使用邊界

它不會替你跳過重要決策

先確認再落地

AI 可以協助產生草稿與方案，但正式寫入、發布、通知、部署與其他外部動作仍需要使用者確認

如果你只需要一次性的統計圖或單張圖片，不必啟動完整工作台流程

完成檢查

看完這頁，你應該能回答

  • 我要管理的是哪一類工作或生活事項
  • 我需要的是工作台、駕駛艙，還是單次報表
  • 完成後我想看到進度、風險、數據或復盤
