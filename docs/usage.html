AI 會怎麼接住你的話

每次只先做一個小決定

  1. 用平常說話

    不需要先說 Skill 名稱，也不需要填固定格式

  2. 先確認真正卡點

    Skill 用兩到四個白話選項協助你確認真正想改善的結果

  3. 說清楚怎麼使用

    確認什麼時候使用、誰使用與完成後要留下什麼

  4. 選一個最小做法

    提出兩到三個最小方案，選定後才進入修改或開發

明確錯誤

功能壞掉時，直接進入診斷

例如

「這個按鈕按了沒有反應」、「頁面報錯」、「資料沒有保存」

這類需求不需要重新做完整痛點訪談，Skill 會先定位頁面、操作、錯誤訊息與實際結果

持續修改

小改動也要留下前後差異

  • 先說現在使用哪個頁面或流程
  • 說明哪個動作不順與期望結果
  • 確認最小修改範圍
  • 修改後實際操作一次
  • 記下下一步與尚未完成項目
