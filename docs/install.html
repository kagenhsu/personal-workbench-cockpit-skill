05 · 開始使用

先準備專用主機，再安裝控制台與連接 AI

這一頁先說明控制台要運作在哪一台電腦，再依序準備工具、安裝 Skill、連接 AI、重新啟動測試，最後開始使用。

專用主機Mac mini M4Windows 小主機

第一步｜準備專用主機

先準備一台專門長時間運作控制台的電腦

Windows 或 Mac 都可以。Mac mini M4 可以作為示範方案；重點是這台電腦專門運作個人控制台或 CEO 控制台，不把日常筆電或 NAS 當成主要主機。

基本配置

16 GB 記憶體／512 GB SSD

適合控制台、資料整理與一般 AI 連接；如果會同時跑多個服務，建議 32 GB／1 TB。

網路與穩定

有線網路、散熱與自動重啟

主機放在固定位置，保持網路穩定，並設定更新、斷電恢復與備份。

本機 AI

要跑模型才需要更高規格

如果只是連接訂閱制 AI，不一定需要獨立顯卡；要在主機本機跑 AI 模型，再另外評估規格。

這台主機的角色

它像控制台的固定基地：執行系統、保存必要資料、提供 AI 可以受控使用的入口。訂閱制 AI 的會員資格，不會自動讓它連到這台主機。

第二步｜準備工具與網路

先把基本工具準備好

  • Windows 或 macOS 作業系統
  • Git，用來取得與更新 Skill
  • 穩定網路與固定主機位置
  • 資料保存位置與備份方式
  • 你平常使用的 AI 工具

查看 Apple Mac mini 技術規格 ↗

第三步｜安裝自己的 Skill

取得檔案，放進 AI 工具能讀到的位置

從 GitHub 取得 Skill，放到對應的技能目錄；確認資料夾內可以直接看到 SKILL.md，不要多包一層同名資料夾。

git clone https://github.com/kagenhsu/personal-workbench-cockpit-skill.git
Codex~/.codex/skills/personal-workbench-cockpit/
Claude Code~/.claude/skills/personal-workbench-cockpit/

第四步｜連接 AI 到系統

訂閱制 AI 不等於自動連上主機

先確認你使用的 AI 工具是否能讀取本機或遠端主機的資料，再選擇登入使用、API 或其他受控連接方式。連接前要設定資料範圍、可以做的動作與人工確認點。

安全原則

不要把密碼、Token 或 API Key 寫進網站、Skill、提示詞或圖片；正式寫入、發布、通知與外部動作都要等你確認。

第五步｜重新啟動測試

讓工具重新讀取 Skill，再做一次測試

  1. 重新啟動 Codex、Claude Code 或使用中的 AI 工具

    讓工具重新掃描 Skill 目錄與目前系統規則

  2. 確認主機與網路正常

    確認控制台服務可以開啟，資料位置與備份方式正確

  3. 先用一句自然語言測試

    不要先做正式寫入，先確認 AI 能理解你的工作問題

第六步｜開始使用

從一件真實工作開始

直接說出今天想完成或需要追蹤的事情，確認 AI 能整理資料、提出建議，並在你確認後留下結果。

我要開始使用我的個人控制台，請先問我今天最需要完成的一件事。
  • 主機可以長時間運作
  • Skill 已被 AI 工具讀取
  • AI 只讀取允許的資料
  • 正式動作前會等待確認
  • 完成結果會回到系統保存

完成安裝與測試後，開始使用自己的系統
